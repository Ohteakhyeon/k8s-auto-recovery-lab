## 1. 문서 목적

오픈소스 애플리케이션 Google Online Boutique를 기반으로 구축할 Kubernetes 운영 환경의 전체 구조를 정의한다.

애플리케이션 소스 관리부터 Docker Image Build, Kubernetes 배포, GitOps 기반 CD, 인프라 IaC, 모니터링, 부하 테스트, 장애 탐지 및 자동 복구까지의 전체 흐름을 하나의 아키텍처로 구성하는 것을 목표로 함.

---

## 2. 아키텍처 설계 목표

- 애플리케이션의 컨테이너 기반 표준화
- Kubernetes 기반 배포 및 Self-Healing
- Terraform 기반 인프라 자동 생성
- CI/CD 자동화
- GitOps 기반 배포 관리
- Prometheus 기반 Metric 수집
- Grafana 기반 상태 시각화
- k6 기반 부하 및 장애 영향 측정
- 장애 발생부터 복구까지의 흐름 관측
- 수동 대응 대비 자동 복구 효과 정량화

## 13. 보안 기본 방향

초기 설계 기준

- Container는 Non-root 실행
- Privilege Escalation 차단
- 불필요한 Linux Capability 제거
- Kubernetes Secret과 일반 설정 분리
- IAM Role 최소 권한 원칙 적용
- Worker Node는 가능하면 Private Subnet 배치
- 외부 접근은 Load Balancer 또는 Ingress로 제한

상세 내용은 Terraform/AWS 설계서 및 Kubernetes 설계서에서 구체화한다.
